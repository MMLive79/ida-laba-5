# Лабораторная работа №5 — Классификация

М.А. Мотовилов, группа 4415, вариант 4. Данные: `bank_loan_default.csv`.

В [выполненном ноутбуке](lab5_classification.ipynb) представлены все 10 основных
пунктов и дополнительные задания **14, 13, 8, 5** с пояснениями и численными выводами:

- **14:** Accuracy дерева на обучающей и проверочной частях для `max_depth=1..16`, таблица и две линии на графике.
- **13:** функция специфичности TNR, проверка граничного случая и сравнение четырёх классификаторов.
- **8:** StandardScaler, MinMaxScaler и MaxAbsScaler для четырёх методов при фиксированных параметрах; таблица всех метрик и сравнительный график.
- **5:** результаты GridSearchCV дерева и сравнение выбранного дерева со стандартными параметрами.

В `results/` сохранены результаты основной части, в `results/additional/` —
пять дополнительных таблиц CSV. Оба новых графика встроены в ноутбук.

Для повторения установите зависимости `pip install -r requirements.txt`, откройте
ноутбук в Jupyter и выполните все ячейки сверху вниз. CSV должен лежать рядом с
ноутбуком. Ячейки создадут папки результатов, таблицы и графики автоматически.

Разбиение 70/30, стратификация и seed 42 одинаковы во всех опытах.
Предобработка обучается только на обучающей части; поиск параметров выполняется
по пятичастной стратифицированной CV с критерием Balanced accuracy.
Сравнение масштабов и кривые глубины — исследовательские результаты одного
фиксированного разбиения. Они не заменяют независимой проверки будущей модели.
